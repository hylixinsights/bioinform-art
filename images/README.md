# images/

Coloque aqui os arquivos de imagem das obras da galeria.

No formulário de submissão (modo admin), no campo **Image URL / path**, referencie
o arquivo por caminho relativo, por exemplo:

    images/health-units.png

Dicas:
- Use nomes sem espaços nem acentos (ex.: `mapping-brazil-ubs.jpg`).
- Otimize antes de subir (idealmente < 1–2 MB por imagem; lado maior ~1600 px).
- Formatos: PNG, JPG, WebP ou SVG.

Assim o `obras.json` guarda só o caminho (leve), e as imagens são servidas como
arquivos — sem o inchaço do base64.
